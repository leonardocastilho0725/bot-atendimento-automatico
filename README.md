# 🤖 Bot de Atendimento Automático em Python

Este é um assistente virtual interativo desenvolvido em Python para automatizar fluxos de atendimento ao cliente. O projeto foi estruturado para ser facilmente adaptável para diferentes plataformas (Terminal, WhatsApp, Discord ou Web).

## 🚀 Funcionalidades Atuais
- **Menu Dinâmico:** Interface interativa com múltiplas opções de escolha.
- **Catálogo de Produtos:** Exibição estruturada de itens e preços (ex: Cardápio de Pizzaria).
- **Consulta de Status:** Simulação de verificação em banco de dados para pedidos.
- **Fluxo de Transição:** Opção de encaminhamento para suporte humano.

## 🛠️ Tecnologias
* [Python 3.x](https://python.org)
* Biblioteca Nativa `time` (para simular tempo de resposta humano)

## 🔧 Como rodar o projeto
1. **Clone o repositório:**
   ```bash
   git clone https://github.com
   ```
2. **Navegue até a pasta:**
   ```bash
   cd bot-atendimento-automatico
   ```
3. **Execute o Bot:**
   ```bash
   python bot-discord.py 
   ```
   *(Nota: O arquivo atualmente chama-se bot-discord.py, mas funciona via terminal)*
